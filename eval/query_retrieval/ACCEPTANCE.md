## 来源与口径

原正向题、逐字答案依据与原 v2 数据保持不变。v3 在首次执行前增加 Q12–Q14，检查逆序及其他主题的并列覆盖。这是扩展开发回归，不是独立留出集或外部人工验收。

重建只改变同一文件修订的 generation / 分块布局。评估使用 `--allow-reindexed-sources`，要求原文件 SHA-256、租户、知识库、文档、修订与冻结来源完全匹配，并在当前授权活动分块中逐字定位全部原答案依据。报告 `source_transitions` 保留新旧批次与分块哈希；默认评估仍要求原冻结分块精确一致，未替换问题或答案来隐藏失败。

`passed` 只表示检索依据完整命中；`answered` 和引用可定位也不等于事实验收通过。逐条事实核对由 Codex 将最终 HTTP 发布陈述与实际引用和原文比对完成，独立于生成模型的 supported 布尔值。未发布草稿不记为正确回答。
