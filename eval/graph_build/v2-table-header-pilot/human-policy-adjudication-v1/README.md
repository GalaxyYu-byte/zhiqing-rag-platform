## 已批准规则

1. 资料实体使用“资料类别”名称；“文件或成果”的内容描述不直接当作别名合并。
2. “检查组”是分类，不能仅据此建 Actor。
3. “申请人应说明”的说明内容按 Field 处理，原 Step 及其关系需重新标注。
4. 状态行的排列不足以证明直接 TRANSITIONS_TO，证据判 INSUFFICIENT。
5. 暂停或退回条件须保留触发后暂停/退回的含义；当前裸 Rule 候选继续待裁决。
